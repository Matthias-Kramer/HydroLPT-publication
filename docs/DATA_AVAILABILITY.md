# Data Availability

This repository contains the HydroLPT source code and the minimal lightweight assets needed to inspect, install, and run the software.

Large hydraulic model files, generated outputs, and paper figure datasets are intentionally not stored in this publication code repository. These files should be archived separately in a research data repository such as Zenodo, Figshare, or OSF, and linked from the final software release and paper.

Recommended release layout:

- GitHub: source code, documentation, citation metadata, smoke tests, and minimal GUI assets.
- Data archive: heavyweight HEC-RAS/BASEMENT inputs, simulation outputs, raster terrain data, benchmarks, helper/export scripts, and full figure reproduction datasets.
