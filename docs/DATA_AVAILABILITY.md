# Data Availability

This repository contains the HydroLPT source code, minimal lightweight assets, and a compact Merced River HEC-RAS plan HDF used by the GUI-loadable Merced test case.

Large hydraulic model files beyond the bundled smoke-test HDF, generated outputs, and paper figure datasets are intentionally not stored in this publication code repository. These files should be archived separately in a research data repository such as Zenodo, Figshare, or OSF, and linked from the final software release and paper.

Recommended release layout:

- GitHub: source code, documentation, citation metadata, GUI-loadable test cases, minimal GUI assets, and the compact Merced HEC-RAS test file.
- Data archive: complete heavyweight HEC-RAS/BASEMENT inputs, simulation outputs, raster terrain data, benchmarks, helper/export scripts, and full figure reproduction datasets.
